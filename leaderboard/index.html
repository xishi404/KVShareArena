A COMMON BASIS FOR COMPARISON

What the numbers mean.

Fixed tasks and source text. Separate measurements for each kind of cost.

Q

Quality recovered

PGR measures the gap recovered between no shared context and full prefill over the same text.

0 · No context1 · Full prefill

PGR can be negative. It is not accuracy.

↘

Three separate costs

Compute: payload computation avoided.
Memory: KV bytes saved vs dense bf16.
Latency: TTFT saved vs same-backend full prefill.

TTFT and throughput describe runtime performance and do not enter the preference score. Negative savings mean extra cost. Cache construction is shown separately.

Missing values remain missing. A method needs every selected metric to receive a preference score.

Preference score · formula and limits ＋

PGR means performance-gap recovered. It equals (method score − no-context score) / (full-prefill score − no-context score). It can be negative or exceed 1.

The quality–cost balance uses the paper's weighted harmonic mean. Let A = clip(PGR, 0, 1). Let C be the weighted arithmetic mean of compute and memory savings, each clipped to [0, 1].

S = A × C / ((1 − t) × C + t × A)

t is the cost weight. For 0 < t < 1, this equals the paper formula with β = t / (1 − t). At 0% cost, S = A; at 100% cost, S = C. The quality-first preset uses β = 0.1 (about 9% cost).

This explorer only scores rows with every selected measurement. It does not use the paper's fallback of dropping missing axes per row, so coverage and rankings can differ. Negative PGR and negative savings remain visible in the raw columns. Equal scores share a rank; a rank difference does not establish statistical significance.

Arrows on PGR mark paired comparisons against free position alignment. The paired intervals in method details refer to differences in the underlying task score, not differences in PGR. An interval covering zero does not prove equivalence.
